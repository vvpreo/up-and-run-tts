# Сервис up-and-run-tts на Silero с админкой

Статус: шаги 1–6 выполнены 1 октября 2026 года, сервис запущен на боксе (`up-and-run-tts-api`, порт 9008), ждёт проверки. dev-nginx пока ведёт на страницу образцов (9018). Решения пользователя: движок — Silero (обе
ветки с переключателем), админка — всё, чем можно управлять в Silero, плюс наша
обвязка; архитектура должна допускать другие движки позже (в этом же или в
отдельных образах).

## Goal

Самодостаточный Docker-сервис русского TTS на процессоре: Silero (все доступные
голоса обеих веток), OpenAI-совместимый API с потоковой отдачей, WebSocket для
текста по кускам и админка для настроек, голосов, словарей и ключей.

## Context

Прогон на Spark ([отчёт](../research/spark-quality-benchmark.md)) показал, что
Silero на процессоре бокса даёт 17× реального времени, не требует GPU, но молча
пропускает цифры и латиницу — нормализация текста обязательна. Лицензия: голоса
`v5_*_ru` некоммерческие (CC BY-NC), `v5_cis_base` + `silero-stress` — MIT.
Модели закрытые (torch.package), клонирования и дообучения нет; «управлять всем» —
значит: модель, голос, частота 8/24/48 кГц, SSML (темп, высота, паузы), ручные
ударения `+`, флаги расстановки ударений и «ё», плюс наши словари и нормализация.

## Устройство

```
main.py                       запуск uvicorn
src/config.py                 переменные окружения
src/settings.py               рантайм-настройки в JSON на томе (defaults, словари, ключи, модели)
src/engines/base.py           интерфейс движка: voices(), synth(text|ssml, voice, sr) -> float32 PCM
src/engines/silero.py         загрузка torch.package из тома, кэш моделей, лок на модель
src/engines/catalog.py        справочник моделей: id, лицензия, URL, ветка (встроенные ударения или нет)
src/text/                     markdown -> нарезка -> нормализация -> словарь -> ударения -> SSML
src/audio/encode.py           wav/pcm (потоково), mp3/opus/flac (целиком) через libsndfile
src/routes/openai.py          POST /v1/audio/speech, GET /v1/models, GET /v1/voices
src/routes/stream.py          WS /v1/audio/speech/stream (текст кусками, отмена)
src/routes/admin.py           /admin: страница + JSON API под basic-auth
src/routes/health.py          /health
src/static/admin/             одна страница без сборки: вкладки Настройки, Голоса, Словарь, Ключи, Тест, Модели
```

Контракт API: `model` = id модели Silero (`v5_cis_base`, `v5_5_ru`, …) или
`tts-1` → модель по умолчанию; `voice` = голос Silero; `response_format` =
`wav | pcm | mp3 | opus | flac`; `speed`; `stream` (по умолчанию выдача по
предложениям для wav/pcm); `sample_rate` 8000/24000/48000. Вход, начинающийся с
`<speak>`, уходит в Silero как SSML без нормализации.

## Steps

1. Каркас: pyproject (uv, torch CPU), config, settings, движок Silero с загрузкой
   весов в том, каталог моделей с лицензиями.
2. Конвейер текста: markdown, нарезка (из бенчмарка), нормализация чисел/дат/
   времени/процентов/валют, латиница, словарь, silero-stress для ветки без
   ударений, сборка SSML с темпом и высотой.
3. API OpenAI + health + Bearer (AUTH_TOKEN и ключи из админки), потоковая
   отдача wav/pcm по предложениям.
4. WebSocket с текстом по кускам и отменой.
5. Админка: страница и JSON API, basic-auth по ADMIN_PASSWORD, иконки стендов.
6. Docker: образ, compose (`up-and-run-tts-api`, порт 9008 на 127.0.0.1 и
   172.17.0.1), том `up-and-run-tts-data`; тесты; README; dev-nginx уже ведёт на 9018 —
   переключить на 9008, когда сервис готов.
