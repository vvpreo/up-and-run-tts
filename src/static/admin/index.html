Обработка текста

Модель включается и выключается целиком; выключение выгружает её из памяти, веса остаются на томе. Некоммерческие модели выключены, пока вы не включите их сами. Внутри модели можно выключить отдельные голоса — они пропадут из /v1/voices, а запрос с таким голосом получит 403.

Кнопка ▶ озвучивает фразу этим голосом; запуск другого голоса останавливает текущий.

Статистика

Словарь произношений

Слово → как произносить. Сравнение без регистра. Ударение — знак + перед ударной гласной: мука → мук+а. Латиницу можно задать кириллицей: Docker → д+окер. Встроенный список терминов (API, GitHub, Python…) применяется, если слова нет здесь. Клиент может прислать свой словарь в запросе (поле dictionary) — он дописывает и перекрывает этот.

Как вызывать

OpenAI-совместимый синтез. Поля сверх OpenAI: stream, sample_rate (8000 / 24000 / 48000), rate, pitch, intensity, dictionary (словарь произношений на один запрос: {"мука":"мук+а"}). model: tts-1 и пустой voice — значения по умолчанию из настроек. Вход, начинающийся с <speak>, уходит в Silero как SSML без обработки.

Форматы: wav и pcm (16 бит, моно) отдаются потоково по фразам; mp3 — потоково по фразам; opus и flac — одним файлом.

Текст по кускам: WebSocket /v1/audio/speech/stream — JSON input.text / input.done / input.cancel, в ответ audio.start → бинарный PCM16 → audio.done. Список голосов: GET /v1/voices, моделей: GET /v1/models, состояние: GET /health.
